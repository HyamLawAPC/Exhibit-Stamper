# Exhibit-Stamper
adds a footer to every page of your exhibit PDFs. Each footer shows the exhibit name and the page number, such as “Exhibit A-1” or “RJN Ex 3-1,” centered at the bottom of the page in Arial 8 point. It runs in your web browser and never uploads your files.

How to use it:

1.      Double-click exhibit_stamper.html. The first time, it needs an internet connection to load its helper libraries.
2.      Drag your exhibit PDFs into the “Exhibit files” box, or click “Choose folder” or “Choose PDF files.”
3.      Type each exhibit’s name in its box. Short names like A or 12 get “Exhibit” added in front. Longer names are used exactly as typed, such as “Ex 1 - Complaint page.”
4.      Click a file to preview it. Use the arrow buttons or keyboard arrow keys to move the footer up, down, left, or right until it sits where you want. The “Move by” setting controls how far each press moves it.
5.      Under “Save as,” choose “One zip file” or “Separate PDFs in a new folder,” and give the output a name.
6.      Click “Stamp all exhibits” and pick where to save. Your original PDFs are never changed, and an existing file or folder is never overwritten.
